# Governance

## Project Status

FileClassifier is an open community project maintained by repository maintainers and contributors.

## Decision Process

- Small changes: handled through normal pull request review.
- Significant changes (architecture, data model, public behavior): discuss in an Issue first.
- If maintainers disagree, the final decision is made by the active lead maintainer for that area.

## Maintainers

Maintainers are contributors with merge permissions and responsibility for:

- Reviewing pull requests
- Triaging issues
- Managing releases
- Enforcing community standards

## Becoming a Maintainer

Typical path:

1. Make consistent, high-quality contributions.
2. Participate constructively in issue/PR discussions.
3. Be nominated by an existing maintainer and accepted by consensus.

## Inactive Maintainers

Maintainers may be moved to inactive status after extended inactivity.  
They can be restored when active again.
