## 一句话结论

FileClassifier 是一个 **Python(FastAPI)+React 的桌面/Web 双模文件归档工具**：以 Excel 元数据表为"真值源"，自动推断可作为文件标识的列，按用户设定的多条件（精确/包含/模糊/范围）筛选出目标记录，再依据文件名中的标识片段把磁盘上的散落文件**定位→复制到归档目录**并产出可审计的报告与日志。零外部服务依赖（仅 pandas + openpyxl + fastapi），刻意做成了"单机可运行"的轻量工程。
