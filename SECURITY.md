# Security Policy

## Supported Versions

We currently provide security fixes for the latest minor release on the `1.x` line.

| Version | Supported |
| --- | --- |
| 1.x | Yes |
| < 1.0 | No |

## Reporting a Vulnerability

Please do not open a public issue for security vulnerabilities.

Use GitHub Private Vulnerability Reporting for this repository, or contact the
maintainers privately through repository security channels.

When reporting, include:

- A clear description of the issue
- Reproduction steps or proof of concept
- Impact assessment
- Suggested fix (optional)

## Response Targets

- Initial triage response: within 3 business days
- Status update cadence: at least once every 7 days until resolution
- Public disclosure: after a fix is available and maintainers coordinate release timing
